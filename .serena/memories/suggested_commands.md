# Suggested commands

## Dev/run
- `bun run dev` (Vite dev server)
- `bun run tauri:dev` (Tauri app dev, uses `backend/tauri.conf.json`)
- `bun run preview` (Vite preview)

## Build
- `bun run build` (tsc + vite build)
- `bun run tauri:build` (Tauri build)

## Lint/format
- `bun run lint` (Biome check)
- `bun run lint:fix` (Biome check + write)

## Type check
- `bun run tc`

## Tests
- `bun run test` (FE + BE)
- `bun run test:fe` (Vitest run)
- `bun run test:be` (cargo test for backend)
- `bun run test:watch` (Vitest watch)
- `bun run test:ui` (Vitest UI)

## Useful system commands (Darwin)
- `rg` (ripgrep) for fast search
- `ls`, `cd`, `pwd`, `cat`, `sed`, `awk`, `find`, `git`
